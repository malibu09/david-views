# David Views — Landing V5.1

Landing de conversión para servicios de edición de video.

## Publicación
Sube `index.html`, `styles.css`, `script.js` y la carpeta `assets/` a GitHub Pages.

## WhatsApp
Antes de publicar, abre `script.js` y coloca el número de David Views en `WHATSAPP_NUMBER`, en formato internacional y solo con dígitos.

## Rendimiento
La interfaz usa HTML/CSS/JS sin frameworks. Los videos de muestra se cargan de forma diferida salvo el hero. Se eliminó el canvas de grano continuo para reducir uso de CPU/GPU conservando las animaciones principales.
