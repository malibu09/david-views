# David Views — sitio final

Landing comercial estática para GitHub Pages.

## Publicación
Sube a la raíz del repositorio: `index.html`, `styles.css`, `script.js` y la carpeta `assets/` completa.

GitHub Pages: `main` + `/(root)`.

## Conversión
WhatsApp configurado al número de David Views. La web presenta portafolio, soluciones, proceso, FAQ y cierre directo por WhatsApp.

## Operación recomendada
Servicio deliberadamente simple: alcance definido, material organizado, una ronda de ajustes menores en proyectos estándar y extras fuera de alcance cotizados aparte.
